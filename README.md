 # antropoLOG* 📓

**Inteligência Artificial aplicada à Pesquisa Qualitativa: O seu Caderno de Campo Digital.**

O antropoLOG* é uma aplicação web desenvolvida para cientistas sociais, antropólogos e investigadores de campo. Utiliza Inteligência Artificial (Google Gemini) para transformar ficheiros de áudio em transcrições literais rigorosas, preservando as marcas de oralidade. O sistema acelera a análise qualitativa ao extrair categorias êmicas, cruzar palavras-chave e gerar mapas de empatia automáticos a partir dos relatos orais.

---

## 🚀 Funcionalidades Principais

* **Transcrição Literal (Verbatim):** Processamento de áudio focado no rigor metodológico. A IA transcreve os relatos na íntegra, mantendo pausas, hesitações e sotaques, sem aplicar resumos.
* **Análise de Áudio a Priori:** Geração automática de Mapas de Empatia estruturados em quadrantes (O que Vê, Ouve, Pensa/Sente, Fala/Faz) com base na perspetiva do entrevistado.
* **Extração Lexical (Cruzamentos):** Identificação de palavras-chave frequentes para mapeamento rápido de tensões e categorias êmicas no discurso.
* **Interface Mobile-First:** Design minimalista e de alto contraste, otimizado para utilização no terreno e ecrãs de portáteis/dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** React (Vite), Tailwind CSS
* **Ícones:** Lucide-react
* **Inteligência Artificial:** Google Gemini API (Modelo 1.5 Flash) via `@google/generative-ai`
