# antropolog-
O antropoLOG* é um caderno de campo digital para cientistas sociais. Usa IA (Google Gemini) para transformar áudios em transcrições literais rigorosas, preservando a oralidade. O sistema acelera a análise qualitativa ao extrair categorias êmicas, cruzar palavras-chave e gerar mapas de empatia automáticos a partir dos relatos.
